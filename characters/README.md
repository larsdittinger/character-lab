# Character workspaces

Create a new workspace from the project root:

```sh
.venv/bin/python tools/new_character.py mage --title "Mage"
```

Keep each character's references, independently measured calibration, scripts, textures, models, clips, accessories and review evidence together here. See [the character contract](../docs/CHARACTERS.md). Finished static or animated GLBs appear in the viewer automatically. Empty scaffolds and references alone are not listed as models.
